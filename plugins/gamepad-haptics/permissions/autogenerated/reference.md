## Default Permission

Default permissions for the gamepad-haptics plugin. Listening to pad connection events also needs the core event permission (`core:event:default`).

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-identify`
- `allow-list-pads`
- `allow-play-frames`
- `allow-stop`
