## Default Permission

Default permissions for the xdg-portal plugin: the read-only queries. The notification, inhibit and open-URI commands are granted one by one.

#### This default permission set includes the following:

- `allow-check-availability`
- `allow-get-theme-info`
- `allow-get-status`
